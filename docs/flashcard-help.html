Medical Search Mode
--mode search
Roles
📋 Researcher
What it does

Prompts for a medical topic, fetches up to 10 PubMed articles via NCBI E-utilities (no API key required), and generates a structured evidence report with article links.

SectionContent
OverviewWhat is currently known about the topic
Key findingsSummary table of retrieved articles
Research gapsIdentified gaps in current evidence
Clinical relevancePractice implications
Article linksNumbered PubMed URLs for download
Input

Interactive prompt — type your medical topic when asked. No files required.

Run
python src\main.py --mode search
python src\main.py --mode search --provider groq
Output
Evidence reportreports/search_*.md
💡 Use article links with Appraisal mode: download PDFs, place in uploads/appraisal/, then run --mode appraisal.

Systematic Review Pipeline
--mode sr
⚠ Research accelerator only. All outputs require human verification. PRISMA 2020 requires dual independent reviewers.
Pipeline Stages
#StageOutput
1Upload PDFs (SHA-256 dedup)data/uploads/upload_manifest.csv
2Relevance screening (INCLUDE/EXCLUDE/UNCERTAIN)data/screened/screening_log.csv
3Data extraction (PICO-anchored)data/extracted/extracted_data.csv
3.5RoB 2.0 (5 Cochrane domains)data/extracted/rob2_assessment.csv
4Meta-analysis (DerSimonian-Laird RE)data/results/meta_analysis_results.csv
5Forest plot (weight-scaled)outputs/figures/forest_plot.png
6Reports (DOCX + HTML + PDF)outputs/reports/
Setup — before every new review
StepAction
1Edit sr\config\prisma_criteria.yaml — set PICO, effect_measure, criteria
2Place RCT PDFs in sr\data\uploads\
3Set ANTHROPIC_API_KEY environment variable
Run
python src\main.py --mode sr              # shows instructions
cd D:\AI_kcMedicalResearch
python sr\main.py --pdf-dir sr\data\uploads
python sr\main.py --pdf-dir sr\data\uploads --effect-measure SMD
python sr\main.py --pdf-dir sr\data\uploads --model claude-opus-4-7
Effect Measure Guide
Outcome typeUseNotes
Continuous, same scaleMDe.g. all studies use VAS 0-10
Continuous, mixed scalesSMDHedges g — safe default for mixed instruments
Binary / eventOR or RRneeds event counts
Key Config Fields (prisma_criteria.yaml)
pico:
  population:   "Adults (>=18 years) with fibromyalgia"
  intervention: "Cognitive-Behavioral Therapy"
  comparator:   "Placebo or active comparator"
  outcome:      "Pain intensity at post intervention timepoint"
  study_design: "Randomised controlled trials (RCTs)"
effect_measure: SMD
inclusion_criteria:
  - "RCT study design"
exclusion_criteria:
  - "Non-randomised designs"

RAG — File & URL Indexing
Automatic at session start

Files placed in the uploads folder are automatically chunked, embedded, and stored in a per-session ChromaDB collection. Content is retrieved and injected into the AI context at each step.

Supported file types
.txt .md .pdf .py .js .ts .json .yaml .sql .sh
URL fetching

Place a .txt or .md file with bare URLs (one per line) in the uploads folder. Each URL is fetched, HTML stripped, and indexed automatically.

# reading-list.md
https://pubmed.ncbi.nlm.nih.gov/12345678/
https://www.example.com/article
