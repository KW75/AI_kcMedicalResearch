# QA Checklist — Topic Writing (Editorial / Commentary)

## Hook and Engagement
- [ ] Opening sentence is arresting — a fact, question, or bold statement
- [ ] Thesis is clear within the first paragraph
- [ ] Piece holds attention throughout — no padding or repetition
- [ ] Closing line is memorable or calls the reader to action

## Argument and Logic
- [ ] Single clear position maintained throughout
- [ ] Each body paragraph makes one distinct point
- [ ] Strongest counterargument acknowledged and addressed
- [ ] No logical fallacies (strawman, false dichotomy, appeal to authority)

## Language and Style
- [ ] Plain English used throughout
- [ ] No unexplained jargon or abbreviations
- [ ] Active voice dominant
- [ ] Sentence length varied — no three consecutive sentences of the same length
- [ ] No padding phrases ("it is worth noting that", "needless to say")
- [ ] No bullet points in the body text

## Structure
- [ ] Opening paragraph: hook + thesis in ≤ 3 sentences
- [ ] Body: 3–5 paragraphs each with a clear topic sentence
- [ ] Closing paragraph restates key message decisively
- [ ] Word count within agreed limit (default 800)

## Accuracy and Ethics
- [ ] All factual claims cited or attributable
- [ ] No fabricated or unverifiable statistics
- [ ] Counterargument represented fairly
- [ ] AI-involvement disclosure appended
- [ ] No stigmatising language

## Formatting
- [ ] Headings in correct Markdown levels (if used)
- [ ] No footnotes (use inline citations)
- [ ] File saved as .md and .docx
