# Validation Criteria

This document is injected into the Validator AI role only. It defines the
checklist used to confirm that the search strategy is complete and correctly
aligned with the PICO question before the article list is approved for
download.

---

## Validation checklist

### PICO alignment
- [ ] Search terms cover all four PICO elements — P, I, C, O
- [ ] Population terms include all relevant synonyms and MeSH terms
- [ ] Intervention terms include all relevant synonyms, drug names, and MeSH terms
- [ ] Comparator terms are represented where relevant
- [ ] Outcome terms are included where they improve precision without
      sacrificing recall

### Database coverage
- [ ] All seven standard SR databases have been searched
- [ ] Database-specific syntax has been applied correctly for each platform
- [ ] MeSH / controlled vocabulary terms have been used alongside free text

### Search construction
- [ ] Boolean logic is correct — OR within elements, AND between elements
- [ ] Truncation has been applied consistently
- [ ] The Cochrane RCT filter or equivalent has been applied to each database
- [ ] Language and date filters are documented and justified

### Results review
- [ ] Total number of results per database is documented
- [ ] Results are not so narrow as to suggest over-filtering
- [ ] Results are not so broad as to suggest the strategy needs tightening
- [ ] Any zero-result databases have been investigated and resolved

### Final decision
- [ ] PICO question and search strategy are aligned
- [ ] Article list is ready for deduplication and download
- [ ] If gaps found — specify which PICO element needs refinement and why
