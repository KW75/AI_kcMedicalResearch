# Medical Search Mode — Output Standards

## Purpose
This guide is injected into every search-mode session.
The Researcher role must follow the output format below exactly.

## Output Format

### For Paper Search (finding a specific paper)
Produce a structured report with these sections:

#### Identification
- Search query used
- Database searched (PubMed)
- Date of search
- Number of results retrieved

#### Best Match
- Full citation: Authors. Title. Journal. Year;Volume(Issue):Pages. DOI.
- PubMed ID (PMID)
- Abstract (reproduced verbatim or summarised if > 300 words)
- Direct PubMed URL

#### Relevance Assessment
- Does this paper match the requested topic? (High / Partial / Low)
- Study design
- Population and intervention
- Key finding in one sentence

#### Further Results (if > 1 result found)
List up to 5 additional relevant papers in abbreviated citation format with PMID.

---

### For Clinical Topic Search
Produce a structured narrative report with these sections:

#### Search Strategy
- PICO elements used to build the query
- Final Boolean string
- Database and date

#### Evidence Summary (≤ 1500 words total)
- What the current evidence shows about this topic
- Level of evidence (GRADE language: High / Moderate / Low / Very Low)
- Key studies (cite at least 3 if available): author, year, design, key finding

#### Clinical Implications
- What does this evidence mean in practice?
- Any gaps, controversies, or ongoing trials worth noting?

#### Reference List
Full citations for all papers mentioned, Vancouver style.

---

## Quality Standards
- Do not fabricate citations — only report papers that are confirmed to exist.
- If PubMed returns no results, say so explicitly and suggest a refined search strategy.
- Effect sizes and p-values must be reproduced exactly from the source.
- Flag any paper that is a preprint (not peer-reviewed) clearly.
- Maximum total word count: 1500 words (excluding reference list).
