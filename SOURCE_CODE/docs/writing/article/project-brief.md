# Journal Article Project Brief

## Purpose
This file tells the Writer role what medical journal article to produce.
Fill in all fields before running:
    python src/main.py --mode writing

## Fields
- **Title**: [Working title of the article]
- **Article type**: [Original research / Review / Case report / Editorial / Letter]
- **Target journal**: [e.g. "NEJM", "BMJ", "JAMA", "Lancet", or "general medical"]
- **Target audience**: [e.g. "Clinicians", "Researchers", "Public health specialists"]
- **Key message**: [The single most important finding or argument]
- **Word limit**: [Default: 3500 for original research. Override here if needed]
- **PICO / Research question**: [Population, Intervention, Comparison, Outcome]
- **Study design**: [e.g. RCT, cohort, meta-analysis, narrative review]
- **Key findings**: [Bullet the main results with effect sizes and confidence intervals]
- **Sources / references**: [List DOIs or paste abstracts below this line]
