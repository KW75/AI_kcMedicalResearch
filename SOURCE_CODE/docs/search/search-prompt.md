# Search Mode Guidelines

## Purpose
Generate accurate, well-structured search summaries for medical research topics
and specific article types. Always include full reference links.

## Topic Search Guidelines
- Summarise the search results in clear, plain English
- Group related findings under thematic headings
- Include a numbered reference list with full URLs at the end
- Flag any results that appear unreliable or non-peer-reviewed
- Aim for 600-900 words in the synopsis body

## Article Search Guidelines
- Extract: Title, Authors, Year, Journal, DOI/URL, Abstract summary
- Classify each result by study design
- When 2 or more similar documents are found (same topic/type):
  * Summarise shared findings, methodology, and recommendations
  * Highlight key differences in scope, population, outcomes, or conclusions
- Comparison section heading: ## Similarities and Differences
- Aim for 150-200 words per article summary

## Output Format
- Use Markdown headings (##, ###)
- Bold key terms
- All URLs must be clickable markdown links: [Title](URL)
- End every report with: ## References
