============================================
Local Setup (Full Features)
============================================

Install Docker Desktop:

    Windows: https://www.docker.com/products/docker-desktop
    macOS:   https://www.docker.com/products/docker-desktop
    Linux:   https://docs.docker.com/engine/install/

Default AI Provider: DeepSeek

    The default provider is DeepSeek (fast, cheap, reliable for all modes).
    Get a DeepSeek API key: https://platform.deepseek.com
    Add it to your .env file: DEEPSEEK_API_KEY=your_key_here

    Provider Fallback Chain (automatic on transient errors):
        DeepSeek -> Qwen -> Groq
    Configure via: FALLBACK_PROVIDERS=deepseek,qwen,groq in .env

    You can override the provider at any time with the --provider flag.

Install Local AI (Optional - Free, No API Key)

    Note: Ollama is available for offline/local use but is NOT the default.
    Large models (36B+) are too slow for production pipelines (coding, writing).
    Ollama works best with small models for quick local testing only.
    Ollama does NOT work for SR mode (requires vision provider: Qwen, OpenAI, Anthropic, or Groq).

    Install Ollama: https://ollama.com/download

        Windows: Download and run the installer
        macOS:   Download and run the installer
        Linux:   curl -fsSL https://ollama.com/install.sh | sh

    Pull a model (first time only, requires internet):

        ollama pull llama3.2

    Ollama will run locally on your machine at http://localhost:11434

    To use Ollama instead of DeepSeek:

        python SOURCE_CODE/main.py --provider ollama

============================================
Windows Users
============================================

One-Click Setup (Recommended)

    1. Open Command Prompt or PowerShell
    2. Clone the repository:

        git clone https://github.com/KW75/AI_kcMedicalResearch.git
        cd AI_kcMedicalResearch

    3. Double-click docker\Docker_setup.bat
    4. Follow the prompts:
        - Choose C: or D: drive
        - Add API keys (DeepSeek recommended as minimum)
        - Choose CLI or UI mode
    5. Start working!

Quick Launch (After Setup)

    CLI Mode: Double-click AI_kcMedicalResearch_CLI.bat
    UI Mode:  Double-click AI_kcMedicalResearch_UI.bat

============================================
macOS Users
============================================

One-Click Setup (Recommended)

    1. Open Terminal
    2. Clone the repository:

        git clone https://github.com/KW75/AI_kcMedicalResearch.git
        cd AI_kcMedicalResearch

    3. Make scripts executable (first time only):

Quick Launch (After Setup)

    CLI Mode: ./Mac_kcMedicalResearch_CLI.sh
    UI Mode:  ./Mac_kcMedicalResearch_UI.sh

============================================
Configuration
============================================

API Keys Setup

After running the setup script, edit the .env file and add your API keys:

    # Default provider (change if desired)
    DEFAULT_PROVIDER=deepseek

    # Fallback chain (comma-separated; auto-tries next on transient errors)
    FALLBACK_PROVIDERS=deepseek,qwen,groq

    # DeepSeek (default - recommended)
    DEEPSEEK_API_KEY=your_key_here      # Get from: https://platform.deepseek.com

    # Local Ollama (optional - free, no API key needed)
    OLLAMA_HOST=http://localhost:11434
    OLLAMA_CONTEXT=32768
    OLLAMA_NUM_PREDICT=8192
    OLLAMA_TEMPERATURE=0.3

    # Other Cloud Providers (optional - add keys if you want to use them)
    GROQ_API_KEY=your_key_here          # Get from: https://console.groq.com
    DASHSCOPE_API_KEY=your_key_here     # Get from: https://dashscope.aliyuncs.com
    OPENAI_API_KEY=your_key_here        # Optional: https://platform.openai.com
    ANTHROPIC_API_KEY=your_key_here     # Optional: https://console.anthropic.com

    # RAG (optional)
    EMBEDDING_PROVIDER=ollama
    EMBEDDING_MODEL=nomic-embed-text

    # CLI theme (auto-detected; override if needed)
    CLI_THEME=dark

Ollama Setup (Optional - For Local/Offline AI)

    1. Install Ollama: https://ollama.com/download

    2. Pull a model (first time only, requires internet):

        # Recommended models (small to large)
        ollama pull llama3.2:3b      # Small, fast (3B) - best for local use
        ollama pull llama3.2         # Medium (8B)
        ollama pull qwen2.5:32b     # Large (32B - requires good GPU)

    3. Verify Ollama is running:

        ollama list                  # Show installed models
        ollama run llama3.2 "Hello"  # Test the model

    Ollama runs completely offline after the model is downloaded!

    Important: Large models (32B+) frequently timeout on coding and writing pipelines.
    For production work, use DeepSeek or another cloud provider.

    Auto-start Ollama (optional):
        Windows: Add to Startup folder
        macOS:   Add to Login Items
        Linux:   Use systemd service

============================================
CLI Flags
============================================

    Flag              Description
    --mode            Select mode: coding, writing, rct_search, search, appraisal, sr
    --provider        AI provider: deepseek (default), ollama, openai, anthropic, groq, qwen
    --model           Specify model name (provider-specific)
    --no-stream       Disable live streaming output (batch mode)
    --resume          Resume from last checkpoint if available
    --report          Writing mode: single-pass report from input/writing/ files
    --revise          Coding mode: Builder, Reviewer, Tester pipeline
    --role            Override the starting role for coding mode
    --sub             Sub-mode for search: 1=Topic Search, 2=Article Search
    --dry-run         Run without making real API calls
    --help-guide      Open interactive HTML help guide in browser
    --ui              Launch Streamlit UI
    --list-sessions   List all session transcripts
    --list-roles      Show available roles and their docs
    --stats           Show session statistics
    --version         Show version number

Deployment & Monitoring

Render (Live Cloud Deployment)

    URL:         https://ai-kcmedicalresearch.onrender.com

    Auto-deploy: Push to main branch triggers automatic deployment
    Build:       pip install --no-cache-dir --prefer-binary -r requirements-render.txt

UptimeRobot (Uptime Monitoring)

    Purpose:     Pings the health endpoint every 5 minutes to prevent free-tier
                 cold starts (Render spins down after 15 min of inactivity)
    Monitor URL: https://ai-kcmedicalresearch.onrender.com/_stcore/health
    Alerts:      Email notification if site goes down; recovery alert when back up
    Dashboard:   https://uptimerobot.com (login: your UptimeRobot account)

    Note: Occasional "Connection Timeout" alerts are normal on the free tier.
    The service auto-recovers within 60 seconds. If downtime persists > 5 min,
    check the Render dashboard for build failures.

============================================
Troubleshooting
============================================

Mac_Setup.sh fails
    Ensure scripts are executable: chmod +x Mac_*.sh

Docker Issues
    Issue                       Solution
    Docker not found            Install Docker Desktop from https://www.docker.com/products/docker-desktop
    Docker not running          Start Docker Desktop from system tray/menu bar
    Build fails                 Check internet connection and Docker logs
    Volume mount errors         Ensure folders exist: input/, output/, data/, reports/
    Docker_setup.bat fails      Run as Administrator, check internet connection

DeepSeek Issues
    Issue                       Solution
    API key not working         Verify key at https://platform.deepseek.com
    Rate limited                Wait a moment and retry; check account balance
    Timeout on large tasks      Increase LLM timeout in .env or try --provider qwen

Ollama Issues (if using --provider ollama)
    Issue                       Solution
    Ollama not found            Install from https://ollama.com/download
    Ollama not running          Start Ollama from Applications (macOS) or Start Menu (Windows)
    Model not found             Run: ollama pull llama3.2
    Out of memory               Use a smaller model: ollama pull llama3.2:3b
    Slow/timeout                Use DeepSeek instead (default); large models are too slow
    Coding pipeline fails       Switch to --provider deepseek (large Ollama models cannot complete Builder/Reviewer/Tester loops)

API Key Issues
    - Check if entered correctly (no extra spaces)
    - For Qwen: Use DASHSCOPE_API_KEY env var
    - For Ollama: No API key needed
    - Check Render env variables are saved

Pipeline Fails
    - Check logs in the UI output area
    - Verify input files are in correct folder
    - Check API key is valid for selected provider
    - For SR mode: Ensure provider supports vision (Qwen, OpenAI, Anthropic, Groq)

Theme Not Detected (CLI)
    - Launcher auto-detects on first run
    - Override with:
        Windows:     setx CLI_THEME dark  (or light)
        macOS/Linux: export CLI_THEME=dark (or light)
    - Close and reopen terminal for changes to take effect

Render/UptimeRobot Issues
    Issue                           Solution
    "Connection Timeout" alert      Normal on free tier; service auto-recovers in ~60s
    Build fails on Render           Check Render dashboard logs; likely OOM or dependency issue
    Site loads slowly first time    Free tier spins down after 15 min; UptimeRobot keeps it warm
    Persistent downtime > 5 min     Check Render dashboard for failed deploy or suspended service
