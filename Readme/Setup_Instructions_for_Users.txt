============================================================
   AI kcMedical Research - Setup Guide
   For first-time users. No technical knowledge needed.
============================================================

You only do this ONCE. It takes about 15-20 minutes, mostly
waiting for downloads. Follow the steps in order.


------------------------------------------------------------
 STEP 1  -  Install Python (the app needs this to run)
------------------------------------------------------------

1. Go to:
   https://www.python.org/downloads/release/python-3119/

2. Scroll to the bottom of the page to the "Files" list.

   - On Windows:  click "Windows installer (64-bit)".
   - On a Mac:    click "macOS 64-bit universal2 installer".

3. Open the file you just downloaded.

4. WINDOWS ONLY - IMPORTANT:
   On the first screen, tick the box that says
   "Add python.exe to PATH", THEN click "Install Now".

   MAC: just click through and accept the defaults.

5. When it says it is finished, close the installer.

------------------------------------------------------------
 STEP 2  -  Download the app
------------------------------------------------------------

1. Go to:
   https://github.com/KW75/AI_kcMedicalResearch

2. Look for the green button near the top that says
   "<> Code" and click it.

3. In the small menu that opens, click "Download ZIP".

4. The download is a compressed folder. Open it (unzip it):

   - On Windows:  find the downloaded ZIP file (usually in
     your "Downloads" folder), right-click it, and choose
     "Extract All...", then click "Extract".

   - On a Mac:    double-click the downloaded ZIP file and it
     will unzip on its own.

5. You now have a folder called "AI_kcMedicalResearch"
   (it may have "-main" on the end - that is fine).
   Move it somewhere easy to find, such as your Desktop
   or Documents.


------------------------------------------------------------
 STEP 3  -  Start the app
------------------------------------------------------------

Open the "AI_kcMedicalResearch" folder, then:

   - On Windows:
     Go into the  scripts  folder, then the  windows  folder.
     Double-click:  AI_kcMedicalResearch_CLI

   - On a Mac:
     Open the "Terminal" app, type the word  bash  followed by
     a space, then drag the file
        scripts/macos/Mac_kcMedicalResearch_CLI.sh
     into the Terminal window, and press Enter.

The FIRST time you run it, the app sets itself up. This takes
a few minutes.

  >>> The screen may look frozen or stuck. THIS IS NORMAL. <<<
  >>> Do NOT close the window. Just wait until a menu appears. <<<

If a message tells you to install Python, go back to Step 1.


------------------------------------------------------------
 STEP 4  -  Choose how the app "thinks" (pick ONE)
------------------------------------------------------------

The app is now installed, but it needs a "brain" to work.
You have two choices. Pick whichever suits you.


  CHOICE A - Free, private, runs on your own computer
  ---------------------------------------------------
  Best if you work with confidential or patient data.

  1. Install "Ollama" from:  https://ollama.com/download
     Open the file and click through to install it.

  2. Open the "Terminal" (Mac) or "Command Prompt" (Windows)
     and type these two lines, pressing Enter after each:

         ollama pull llama3.2
         ollama pull nomic-embed-text

     (These download the free AI. It may take a while.)

  3. That's it. The app will find it automatically.


  CHOICE B - Cloud AI (needs an account key)
  ------------------------------------------
  Best if you don't want large downloads. Note: your text is
  sent to an outside company, so do NOT use this for
  confidential or patient-identifiable data.

  1. In the app folder, find the file called  .env.example
     Make a copy of it and rename the copy to just  .env

  2. Open  .env  in Notepad (Windows) or TextEdit (Mac).

  3. Paste in the API key your team lead gives you, next to
     the matching provider name, then save the file.


------------------------------------------------------------
 DONE
------------------------------------------------------------

Start the app again (Step 3) whenever you want to use it.
After the first time, it opens straight to the menu.

Stuck? Take a screenshot of what you see and send it to your
team lead or IT contact.
