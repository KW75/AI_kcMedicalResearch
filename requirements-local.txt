# requirements-local.txt - pinned install for local desktops (Windows + macOS)
#
# WHY THIS FILE EXISTS:
# The open-ended pins in requirements.txt / requirements-base.txt let pip pull
# bleeding-edge pyarrow (via chromadb and streamlit). On macOS those newest
# versions have no prebuilt wheel, so pip builds from source and fails with
# "can't find Rust compiler" (Known Issue #19).
#
# This file pins the exact versions that ship prebuilt wheels for BOTH
# macosx_x86_64 (Intel) and macosx_arm64 (Apple Silicon) on Python 3.11,
# so colleagues never hit a source build. Verified working on macOS 11
# (Intel) with python.org 3.11.9, 2026-09-02.
#
# Install:  pip install -r requirements-local.txt
# Requires: python.org Python 3.11 (NOT Anaconda - see README setup notes).
