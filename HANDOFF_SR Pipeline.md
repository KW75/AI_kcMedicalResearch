RCT Search — why the five fibromyalgia papers were not found:

This is a real and important limitation. Three separate issues are likely combining. First, the search is restricted to randomized controlled trial[pt] as a publication type filter in PubMed, which is very strict and misses trials indexed as clinical trials, controlled clinical trials, or comparative studies. Second, PubMed only returns 20 results and the ranking picks from those 20 — if the target papers are not in the first 20 PubMed hits they are invisible to the pipeline. Third, the pipeline only searches PubMed via API — the seven database search strings generated by the Searcher agent are displayed in the report but never actually executed against EMBASE, PsycINFO, CINAHL, Cochrane CENTRAL, or Web of Science where several of these fibromyalgia CBT papers are more prominently indexed.

Recommended fixes for RCT search:

    Broaden the publication type filter from randomized controlled trial[pt] to also include clinical trial[pt] and remove the [pt] restriction entirely as a fallback, using MeSH terms and keywords to enforce study design instead
    Increase the PubMed fetch limit from 20 to 50 or 100 results before AI ranking
    Add a study-design field to the PICO that accepts "RCT or quasi-experimental or controlled trial" rather than RCT only, since several CBT fibromyalgia studies use crossover or waitlist designs that may not be indexed as RCTs
    Consider adding a Cochrane CENTRAL API call since CENTRAL has the most comprehensive RCT coverage and has a free REST API
